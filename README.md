# F Hasan Production

Situs statis F Hasan Production dengan desain neon dari Stitch untuk layanan IT, website, desain kreatif, dan live streaming.

## Menjalankan situs

Buka `index.html` di browser atau jalankan dengan server statis, misalnya `python3 -m http.server`.

## Halaman

- `index.html` — beranda
- `layanan.html` — layanan
- `portfolio.html` — portofolio dan filter kategori
- `harga.html` — paket harga
- `tentang.html` — profil singkat
- `kontak.html` — kontak konsultasi
